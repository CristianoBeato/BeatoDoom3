## BEATO-DOOM3: ( as future beatoTech1)

Beato Doom 3 (soon to be BeatoTech1) is a project aimed at modernizing the Doom 3 engine, idTech4, similar to other projects like RBDOOM3-BFG, Dhewm3, fhDOOM, StormEngine, and OpenTech.

Its goal is to serve independent purposes, functioning as a standalone engine while also acting as a research project for new rendering techniques and optimization implementations. My milestones for the projec is in the Plans.md 

If this project aligns with your interests, you are welcome to clone it.

Please see id-README.txt for the original README from id software.
